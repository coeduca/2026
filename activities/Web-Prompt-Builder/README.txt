WEB Rrompt Builder
==================

Archivos:
- index.html
- styles.css
- app.js
- rigo.js
- perfil.jpg  <- cada estudiante debe colocar aquí su propia foto usando exactamente este nombre

Uso:
1. Mantén todos los archivos en la misma carpeta.
2. Abre index.html o publica la carpeta en GitHub Pages.
3. Completa Nombre, Edad, NIE, Institución, Grado, descripción y gustos.
4. El progreso se guarda automáticamente en localStorage.
5. Copia el prompt generado y entrégalo a una IA para crear la página personal.

El builder usa un favicon emoji de Rigo (🦎). El prompt también solicita que la página final incluya un favicon emoji sin necesitar archivos extra.

Nota de privacidad: el NIE se guarda localmente en el navegador y el prompt indica que no debe mostrarse completo en la página pública de GitHub Pages.
